Welcome. This deck introduces how BRC-Analytics brings together three foundations — AI agents, the Galaxy workbench, and national HPC infrastructure — to move from static genome portals to dynamic biological inquiry.

What Is BRC-Analytics?

The initial idea was to connect genome assemblies and associated annotations directly to reproducible analysis workflows — uniting NCBI Datasets, Galaxy, and the UCSC Genome Browser atop Texas Advanced Computing Center (TACC) infrastructure.

What is BRC-Analytics
BRC-Analytics began by wiring curated genome assemblies from NCBI Datasets directly into Galaxy analytical workflows and UCSC visualization, backed by TACC compute so users never have to stage indices manually.

Components: Galaxy

  • Open Execution Fabric (usegalaxy.org): Web-scale analytical platform running version-pinned bioinformatics tools with zero local software installation.
  • End-to-End Provenance: Every job records tool versions, containers, parameters, and lineage in a shareable History that extracts into reusable workflows.
  • IWC Workflows & User-Defined Tools: Combines community-vetted IWC pipelines with container-native GalaxyUserTool wrappers launched cleanly in one click.
  • Agent-Native Infrastructure: Full REST API and Galaxy MCP allow AI assistants to launch, monitor, and inspect analyses alongside human scientists.

Why This Matters

No manual FTP scraping, broken chromosome names, or stale gene models — NCBI Datasets keeps every BRC reference synchronized across compute and visualization.

Components · NCBI Datasets
NCBI Datasets replaces ad-hoc genome downloads with versioned data packages where assembly FASTAs, gene models, and taxonomy metadata arrive ready for downstream Galaxy indices and UCSC hubs.

Components: TACC Infrastructure

High-Throughput Compute
Dedicated Galaxy compute nodes alongside petascale HPC systems (Stampede) power assembly, mapping, variant calling, and archive-scale scans.
Corral & Ranch Storage
Shared high-speed Corral storage co-locates pre-built reference indices and user datasets directly next to compute, backed by Ranch archival storage.
Jetstream2 Elastic Cloud
On-demand NSF ACCESS cloud capacity hosts interactive notebooks, specialized portals, and elastic container execution for peak outbreak surges.
Texas Advanced Computing Center (UT Austin)

TACC absorbs the operational weight of terabyte-scale indices and parallel SLURM scheduling so every researcher accesses national-scale genomics with zero sysadmin overhead.

Components · TACC
TACC underpins usegalaxy.org and BRC-Analytics: dedicated Galaxy servers, Corral shared storage with pre-cached reference genomes, Stampede HPC capacity, and Jetstream2 cloud instances.

And Then Agentic AI Happened

Agentic AI Emergence
Within four years, frontier models moved from single-turn text chat in late 2022 to deep reasoning in 2024, coding/CLI agents in 2025, and multi-agent MCP workflows in 2026 — directly reshaping how scientists interact with tools like Galaxy.

Agentic AI Will…

01
Ask Actual Biological Questions
Revolutionize the way we do biology because scientists spend their focus formulating evolutionary, clinical, and mechanistic hypotheses — instead of fighting file formats, CLI flags, and pipeline boilerplate.
02
Reinterpret Existing Data in Myriad Ways
Unlock already existing public datasets across assemblies, transcriptomes, and raw read archives — testing entirely new cross-study questions at negligible marginal cost.
Grounded Execution Matters

Free-text LLM guesses do not advance biology. Pairing agentic reasoning with Galaxy workflows, MCP tools, and TACC provenance makes exploratory hypothesis testing verifiable and reproducible.

Biological Impact
Two transformations follow when agents can drive real bioinformatics tools: researchers think in biology rather than syntax, and existing public sequencing archives gain a second life across countless new questions.

The Vision for the Future

Architecture & Vision
The integrated architecture links BRC-Analytics directly to interactive standalone web portals (hyphaeon, rhizaeon, hyphy3, chronaeon, bushwhacker, trace5, rhiztype, eggman, squint, logan, lexicmap) and through Organism Pages to both precomputed Pangenome tracks (including bionym) and parameterized Galaxy tools and workflows (adding varLoop, exprLoop, bindLoop, and disassembler).
